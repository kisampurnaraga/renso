# Audius music and local bilingual speech

The production app offers an explicit Original/Audius source selector in Mood Room. Search is requested only by pressing Search; it returns up to 12 publicly streamable songs, excluding unavailable, unlisted, deleted and gated tracks. Artist attribution, source link and the track's declared license are shown. Audius catalog access does not mean the recordings are public domain or cleared for downloading, advertising or reuse. Playback follows Audius platform terms; do not redistribute tracks. The original procedural music remains available without network access.

Server routes: GET /api/music/search?q=... and GET /api/music/stream/:id. The fixed official API origin, 12-second upstream timeout, input validation, bounded 60-second catalog cache and per-client rate limits limit requests. Streaming resolves fresh track metadata and redirects to the current Audius stream; audio is not buffered through Vercel. Optional AUDIUS_API_KEY can identify a free-tier application; no Spotify/Premium account or bearer token is required by this implementation. If Audius changes anonymous access, configure the application key. Upstream 429 retains numeric Retry-After; errors are sanitized. Audius receives search terms and playback requests, never Renso conversation text. No recording is sent to the AI model.

Speech controls offer device speech and Supertonic 3 for Indonesian/English, F1/M1 voices. Natural speech is opt-in: the user must allow the large model download. Inference runs in a dedicated browser worker using ONNX Runtime Web 1.24.3 (WASM, one thread); initial page load does not download the models or WASM. Model assets are pinned to supertone-oss-archive/supertonic-3 revision aafc6e32416a594460b32413efc49d7fe4ce6d46, fetched from Hugging Face. Budget hundreds of MB of download and additional RAM; prefer Wi-Fi. Hosted-model availability and CORS are dependencies, and low-memory phones may fail. Device speech stays selectable with a clear label; failures do not silently claim natural output. Text is limited to 1,200 characters per synthesis and split into bounded chunks. The language selection controls pronunciation, not translation.

Cancel terminates active inference/download and clears audio URLs; a new reply, persona change, source change or hidden tab stops voice. Successfully loaded models are retained only within the current worker; stop/changes release the worker. Natural speech has a four-minute timeout and never autoplays on receiving a chat reply. Music source changes stop the previous music source; mood selection no longer activates work mode or resets the chat.

Vendored helper source: supertone-oss-archive/supertonic commit 1e9799e964ea4c0dad7cde993b65c3c813a7b373, web/helper.js. Modifications: WASM-only runtime, timed JSON fetches/status checks, bounded long-sentence chunks. MIT notice is served at /licenses/Supertonic-MIT.txt. Model license is OpenRAIL-M, linked from the UI, and is separate from the code license. The upstream repository is archived; we own ongoing maintenance of the integration. No voice cloning, remote TTS API charge or promise of naturalness on every device.

Acceptance: node tests cover provider validation, restricted tracks, catalog caching, timeout/malformed/429 errors, fresh stream lookup and route redirects. Build checks TypeScript and worker/WASM emission. Live smoke must check search, playback, stop/source switch, device speech, actual natural audio synthesis and cancellation. Listening quality and memory on a physical Android phone remain a separate user test. Rollback: deploy the prior production commit; no database migration is involved.
